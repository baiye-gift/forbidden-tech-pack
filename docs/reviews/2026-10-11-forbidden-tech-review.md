# 2026-10-11 禁忌建筑独立审查

用户要求修复完成后由单独智能体审查。`/root/independent_review` 仅只读审查和运行宿主，不参与实现、不修改文件。本报告由实现智能体整理审查者返回的发现与最终结论。

## 范围与发现

覆盖付款/欠压结算、冷却转存与排放、轨道过滤、移除及施工计划、存档字段与库存顺序、五台作者美术预览和动画组件。首次审查发现 4 项 P2，二次发现 1 项 P2；未确认 P1。

| 问题 | 最终处理及审查结果 |
|---|---|
| 连续工作转欠压时实际支付额度因冷却时间桶丢失 | Powered Postfix / Unpowered Prefix 同步结算，IsSettling 阻止普通回调消费回执，冷却共用原生电网 epoch；闭环 |
| 编译器外壳有固定满液位 | 五台图集统一调整，移除透明假液罐及伪料位条；已查看最新作者预览，闭环 |
| 移除开始后新生成反应炉仍能运行 | OnSpawn 与模拟回调执行 SafeRemovalStarted 守卫，覆盖延迟 SaveData；闭环 |
| 五种在建计划未取消、统计或退款 | 全部稳定 ID 的计划返还施工库存、发原生 Cancel；待取消计划继续阻止完成；宿主独立通过，闭环 |
| 大库存被管路仅接受微量时绕过排放间隔 | 先检查实际小包后的间隔，再判断候选批量；闭环 |

最后一项独立复核：热仓 6 kg，原生实际输出 0.01 kg 后，立即及 0.2 秒禁止继续输出，恰好 2 秒恢复允许。新增回归覆盖候选 ≥5 kg、实际接受 <5 kg，而非只检查小库存尾料。

## 独立验证与结论

- 独立运行最终编译宿主：73 项生产行为、18 项实际付款适配器检查通过。
- 独立运行安全移除宿主：施工库存退款、延迟取消阻止完成、再次原生 Cancel 移除计划通过。
- 已核对原生方法/IL、稳定 ID/Storage 顺序、五台最新作者预览；未发现其他确认的付款、混合缓冲、施工返料 P1/P2。
- 最终结论：上述 5 项全部闭环，当前审查范围内无确认剩余 P1/P2。该结论不是无缺陷保证。
