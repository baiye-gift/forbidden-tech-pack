# 选择性分子筛系统设计规格

日期：2026-10-04  
状态：已完成方案设计，等待书面规格复核  
目标项目：Oxygen Not Included / Forbidden Technology Pack

## 1. 目标与设计边界

本功能为游戏增加一种原版不具备的“选择性边界”能力：建筑结构在持续保持气密、液密的同时，只允许玩家指定的气体或液体以受控方式跨越边界。

V1 只包含两个核心建筑：

- **选择性分子筛砖**：1×1，实体墙体，可旋转，用于选择性跨膜输运。
- **选择性分子筛门**：1×2，持续保持 Sim 层气液隔离，同时允许复制人通行，并具备与膜砖相同的筛分能力。

设计优先级如下：

1. 不修改全局气体、液体或扩散规则。
2. 不通过膜网络替代原版电线系统。
3. 不吞质量、不静默删除缓存、不制造隐藏泄漏。
4. 被动模式免费但较慢；主动模式耗电但更快，并支持单向与逆浓度输运。
5. 大面积膜墙的吞吐与功耗按处理面积线性扩展。
6. 玩法规则必须可预测，避免复杂压力、浓度和相变公式。

## 2. 总体架构

主体采用“**实体隔离格 + 局部直接质量传输**”方案。

膜砖和膜门在 Sim 层始终作为实体隔离边界存在，普通气体与液体不能自然穿过。跨膜筛分由建筑自身组件定时读取边界两侧相邻 Sim Cell，根据白名单、工作模式、方向、目标兼容性和供电状态，执行受控质量转移。

概念流程：

```text
源侧 Cell
   ↓
[读取元素/质量/温度/病菌]
   ↓
[筛选规则 + 模式 + 调度]
   ↓
[直接跨格转移 / 主动微缓存]
   ↓
目标侧 Cell
```

不建立隐藏管网，不修改全局 diffusion，不让膜建筑成为普通输送管道的替代品。

核心逻辑拆分为：

- `MembraneTransferCore`：单处理单元的物质判断与转移。
- `MembraneBuildingState`：模式、方向、白名单、调度、优先级等配置。
- `MembraneBuffer`：主动模式单元素微缓存。
- `MembraneNetworkManager`：膜节点连通关系与内部供电网络。
- `MembranePowerSource`：外部原版电网入口、优先级和故障切换状态。
- `SelectiveMembraneDoor`：门权限、锁定、导航和动画，复用膜处理核心。

## 3. 选择性分子筛砖

### 3.1 基础属性

- 尺寸：1×1。
- 为实体建筑格，阻挡普通气体、液体和复制人。
- 参与正常房间边界判定。
- 热传导完全由建造材料属性决定，不获得额外隔热加成。
- 高压不会导致破裂、损坏或失效。

### 3.2 输运轴

膜砖可以旋转：

- 水平状态：只处理左侧与右侧相邻 Cell。
- 垂直状态：只处理上侧与下侧相邻 Cell。

任何时候都不会同时进行四方向交换。旋转只影响物质传输轴，不影响膜网络供电连接。

## 4. 选择性分子筛门

### 4.1 基础属性

- 尺寸：1×2。
- 支持复制人通行。
- 支持原版门式通行权限。
- 支持手动锁定。
- 支持自动化信号控制锁定/解锁。
- 无论门动画处于打开、关闭或复制人正在通过，Sim 层气体/液体直接泄漏始终为 0。
- 锁门只影响复制人通行，不停止膜筛分能力。

### 4.2 零泄漏通行原则

门不得通过“真正打开实体 Cell”实现通行。正确模型为：

- Sim 隔离持续存在；
- 复制人通过局部 Nav Transition 或等价的短距离内部过渡机制穿越门体；
- 门动画只表达机械开合，不改变气液隔离状态。

如果当前 ONI API 无法直接在实体 Cell 上完成门式导航，则使用门两侧局部入口/出口 Transition 作为备选，但仍禁止通过临时开放 Sim Cell 实现通行。

### 4.3 双处理单元

1×2 门视为两个独立膜处理单元。上下两格分别读取各自两侧环境，独立判断是否可传输。

因此：

- 最大吞吐量为单格膜砖的 2 倍；
- 主动满载功耗为单格膜砖的 2 倍；
- 每个处理单元拥有独立主动缓存；
- 门仍只提供一个统一配置界面。

## 5. 元素白名单

每个膜建筑拥有独立白名单，可同时包含多个气体和液体元素。

规则：

- 支持气体与液体。
- 不支持固体。
- 默认白名单为空，避免刚建成时意外输运。
- 每次实际转移只处理一种元素。
- 不允许覆盖目标 Cell 中不同元素。
- 不在膜内部进行元素相变。

被跨膜输运的物质需要保留质量、温度/热量和病菌信息。

## 6. 被动模式

### 6.1 行为

被动模式：

- 不耗电；
- 双向；
- 无内部缓存；
- 固定最大通量；
- 只处理白名单元素。

### 6.2 同元素交换

如果两侧为同一种允许元素，则由质量较高的一侧向质量较低的一侧传输。

为避免过冲，单次实际转移量不得超过“两侧质量差的一半”。同时还受该处理单元本次更新周期最大通量限制。

### 6.3 真空目标

一侧为允许元素、另一侧为真空时，可以向真空侧传输。

### 6.4 不同元素

如果两侧当前元素不同，即使两种元素都位于白名单中，被动模式也不进行传输。

原因是 ONI 单个 Sim Cell 不能同时容纳两种元素；V1 不通过覆盖目标元素或隐式混合绕过该限制。

## 7. 主动模式

主动模式提供：

- 强制定向输运；
- 支持逆浓度/逆质量差输运；
- 更高额定通量；
- 单元素微缓存；
- 需要供电。

方向只能沿当前膜轴设置：左、右、上、下中的有效两个方向之一。

主动模式不会因为目标侧同元素质量更高而停止，只要目标满足接收条件，就继续按设定方向输运。

## 8. 主动微缓存

### 8.1 目的

微缓存只用于解决目标侧暂时被其他元素占据时的时序阻塞，不作为隐藏储罐。

例如源侧为 H₂、目标侧为 O₂，且 H₂ 在白名单中：主动膜可先把少量 H₂ 吸入缓存，等目标侧变为真空或 H₂ 后再释放。

### 8.2 规则

- 每个处理单元只有一个缓存。
- 缓存同一时刻只能保存一种元素。
- 缓存容量建议等于该处理单元“1 秒额定主动通量”。
- 缓存非空时不得切换到另一元素。
- 断电后停止继续吸入，但保留缓存。
- 重新供电后继续排放/输运。

初始建议容量：

- 气体：500 g/处理单元。
- 液体：2 kg/处理单元。

### 8.3 拆除行为

存在缓存时不得静默删除物质。

拆除前：

1. 停止继续吸入。
2. 优先尝试将缓存退回源侧。
3. 如果源侧不兼容，则保持“等待内部介质排空”状态。
4. 缓存排空后再完成拆除。

V1 不允许通过拆除复制、删除或凭空生成缓存物质。

## 9. 多元素调度

支持两种调度方式。

### 9.1 自动轮询

默认模式。对白名单中当前可传输元素进行轮询：

```text
H₂ → O₂ → CO₂ → H₂ → ...
```

当前不存在或不满足条件的元素直接跳过。

### 9.2 优先级模式

玩家可定义元素优先顺序，例如：

```text
1. Hydrogen
2. Carbon Dioxide
3. Oxygen
```

只有在缓存为空时重新选择元素。缓存非空时必须先处理当前缓存元素。

## 10. 膜内部供电网络

### 10.1 连通规则

膜砖与膜门本身构成内部供电母线，不增加独立控制器建筑。

两个膜节点只有在**共享完整的一条边**时才连通：

- 上下接触：连通。
- 左右接触：连通。
- 斜角接触：不连通。
- 中间有空格：不连通。

门自身占据的两个格子内部天然视为同一个节点。

### 10.2 供电入口

任何膜砖或膜门都可以成为外部供电入口。只要连通网络中的任意节点接入原版电线，该膜网络即可使用此入口为主动功能取电。

内部母线只允许给膜系统自身供电，绝不能向普通建筑输出电力。

因此膜网络不是隐藏普通电线层，也不能替代高负荷导线、电线桥或变压器。

## 11. 多外部电网与主电源选择

同一个膜网络允许连接多个不同原版电路，但这些电路永远不能通过膜网络彼此短接。

同一时刻只有一个外部电源承担膜网络功耗，其余作为备用。

### 11.1 入口优先级

每个供电入口可设置 1～9 级优先级。

默认按接入顺序分配稳定优先关系。相同优先级下使用确定性稳定排序，禁止随机或逐帧切换。

同一个原版 Circuit 如果从多个膜节点接入，应识别为同一外部电源，不重复计为多个独立电网。

### 11.2 自动故障切换

规则：

- 当前主电源无法满足膜网络需求持续约 2 秒后，尝试下一个优先级的电源。
- 更高优先级电源恢复后，需要连续稳定约 5 秒才切回。
- 切换期间绝不并联两个电网。
- 如果所有电源都无法满足满负载，则从当前最高优先级可用电源取电，并降低主动膜工作通量。

该防抖规则用于避免电源边缘状态导致 A/B 电网频繁来回切换。

## 12. 主动功率与吞吐

主动模式采用“固定额定功率 + 实际供电比例决定实际通量”。

公式：

```text
实际通量 = 额定通量 × 实际供电比例
```

低功率只降低速度，不改变：

- 元素筛选结果；
- 传输方向；
- 密闭性；
- 缓存规则。

没有可处理物质的主动膜不产生工作负载。

### 12.1 初始平衡参数

V1 初始建议值：

| 类型 | 被动通量/格 | 主动通量/格 | 主动额定功率/格 |
|---|---:|---:|---:|
| 气体 | 约 167 g/s | 500 g/s | 120 W |
| 液体 | 约 0.67 kg/s | 2 kg/s | 240 W |

设计关系：被动最大通量约为主动额定通量的 1/3。

1×2 分子筛门按两个处理单元计算，因此满载时对应 2 倍通量和 2 倍功耗。

这些数值为首轮实机平衡参数，允许在测试阶段调整，但不得改变“被动免费且明显更慢、主动耗电且明显更快”的设计关系。

## 13. 面积扩展

不存在膜网络级隐藏总吞吐上限。

每个处理单元独立拥有额定通量，因此总处理能力按有效膜面积线性增长：

```text
1 格 = Q
5 格 = 5Q
20 格 = 20Q
```

主动功耗也随实际工作处理单元数量线性增长。

## 14. 热学与相变

膜建筑自身的固体导热完全由建造材料决定，不提供额外隔热或导热模式。

跨膜物质保持自身热量/温度。质量加入目标 Cell 后，由 ONI 原生 Sim 继续处理正常热交换和相变。

膜组件本身不主动：

- 加热；
- 制冷；
- 蒸发；
- 液化；
- 冻结；
- 改变元素类型。

## 15. 高压与结构可靠性

V1 不实现膜破裂、压差损伤或最大耐压。

无论两侧压力差如何，膜砖和膜门均保持结构完整和气液隔离。压力只影响周围原版环境，不改变膜本体可靠性。

## 16. UI 与玩家交互

每个膜建筑提供以下配置区。

### 16.1 膜设置

- 模式：被动交换 / 主动输运。
- 主动方向：沿当前膜轴选择方向。
- 允许元素：气体/液体多选白名单。

### 16.2 调度

- 自动轮询。
- 元素优先级。

### 16.3 网络状态

展示：

- 所属膜网络标识。
- 节点数量。
- 处理单元数量。
- 当前工作处理单元数量。
- 当前功率需求。
- 实际供电。
- 当前工作效率。
- 当前主供电入口及优先级。
- 备用入口状态。

### 16.4 批量配置

支持：

- 复制设置。
- 粘贴设置。
- 一次性“应用到当前连通膜网络”。

“应用到网络”只执行一次性复制，不建立永久共享配置。复制后每块膜仍可单独修改。

## 17. 网络拓扑与更新策略

`MembraneNetworkManager` 只维护本 Mod 建筑的四方向连通关系。

网络重建应采用事件驱动，而不是每帧全图扫描。以下事件触发局部或相关网络重算：

- 建造膜节点。
- 拆除膜节点。
- 节点相邻关系发生变化。
- 加载存档后初始化。

膜传输处理建议以约 200 ms 级别的固定 Sim 更新间隔执行，避免依赖渲染帧率。

网络 ID 不写入存档；加载后根据实际建筑位置重新构建，以降低版本升级后的存档脆弱性。

## 18. 存档数据

每个建筑需要保存：

- 工作模式。
- 输运轴/方向。
- 元素白名单。
- 调度方式。
- 元素优先级。
- 外部供电入口优先级。
- 主动缓存元素。
- 缓存质量。
- 缓存热状态。
- 缓存病菌状态。

临时网络拓扑、网络 ID、当前主电源选择可以在加载后重建，不应作为长期稳定存档依赖。

## 19. 异常处理原则

所有异常优先遵守以下顺序：

1. 不泄漏。
2. 不吞质量。
3. 不跨电网短接。
4. 不错误传输元素。
5. 不确定时宁可暂停工作。

具体行为：

- 目标格元素不兼容：等待。
- 缓存已满：停止吸入。
- 无供电：主动模式停止，被动能力与密闭性不受影响。
- 供电来源无法安全确定：不取电。
- 门导航异常：禁止复制人通行，但继续保持气液隔离。
- 缓存无法释放：保留缓存并阻止破坏性拆除。

## 20. 视觉方向

整体视觉必须贴近 ONI 的手绘工业机械风格，避免廉价霓虹、巨大光环、安全检查门或通用赛博朋克外观。

### 20.1 膜砖

建议视觉元素：

- 厚实工业框架。
- 中央微孔/复合膜面。
- 边缘机械压紧结构。
- 四边低调的内部供电触点。
- 主动工作时显示弱化的方向箭头、轻微膜面波纹或低亮度边缘脉冲。

相邻膜砖的触点在视觉上形成连续结构，但不做高亮“霓虹电网”。

### 20.2 分子筛门

建议视觉元素：

- 厚重金属框架。
- 中央持续存在的半透明膜场或微孔膜结构。
- 复制人通过时机械结构短暂展开，但视觉上仍表达“膜边界没有消失”。
- 少量状态灯用于表达主动/被动、供电和锁定状态。

## 21. 科技与材料定位

功能定位为中后期技术，不作为最终毕业科技，也不在早期提供。

推荐解锁阶段：玩家已经能够稳定获得精炼金属与塑料之后。

初始材料建议：

| 建筑 | 精炼金属 | 塑料 |
|---|---:|---:|
| 分子筛砖 | 100 kg | 25 kg |
| 分子筛门 | 200 kg | 50 kg |

V1 优先挂接合适的原版中后期科技节点，不新增独立科技树，以降低兼容与维护成本。

## 22. V1 明确不做

V1 不包含：

- 固体筛分。
- 远距离传输。
- 膜网络给普通建筑供电。
- 隐藏管网。
- 膜破裂和压差耐久系统。
- 复杂真实浓度扩散公式。
- 自动加热或制冷。
- 膜内相变。
- 全局 Sim 规则修改。
- 独立膜控制器建筑。
- 独立自动化总线。

## 23. 技术风险与验证顺序

正式实现前应优先验证以下高风险点：

1. ONI 当前版本安全的 Sim 质量移除/添加接口，以及温度与病菌守恒方式。
2. 实体隔离状态下，分子筛门的复制人 Nav Transition 是否可稳定实现。
3. 原版电网接入检测、可用功率判断和安全扣电方式，确保不同 Circuit 不被膜网络实际合并。
4. 建筑拆除、保存/加载时主动缓存是否可以完整守恒。
5. 大量膜节点同时运行时的 SimMessages 调用量和网络重建成本。

如果某个 API 无法满足零泄漏或守恒要求，应优先调整局部实现，而不是放宽核心玩法约束或引入全局 Sim Patch。

## 24. 测试矩阵

至少覆盖：

| 场景 | 预期结果 |
|---|---|
| H₂ / Vacuum，被动 | H₂ 按被动通量向真空侧移动 |
| H₂ / H₂，不同质量 | 向低质量侧平衡且不发生过冲 |
| H₂ / O₂，被动 | 停止传输 |
| H₂ → O₂，主动 | H₂ 进入微缓存并等待目标兼容 |
| 低质量 H₂ → 高质量 H₂，主动 | 继续按方向输运 |
| 高压液体 | 膜不损坏、不泄漏 |
| 主动模式断电 | 主动停止，缓存保留，密闭不变 |
| 门打开 | 普通气液泄漏始终为 0 |
| 复制人连续穿门 | 通行正常且普通气液泄漏为 0 |
| 门锁定 | 复制人停止通行，膜筛分继续 |
| 网络中间拆砖 | 自动分裂为两个网络 |
| 两个外部电网接入 | 只使用一个主电源，不短接 |
| 主电源功率不足 | 持续约 2 秒后切备用 |
| 高优先级电源恢复 | 稳定约 5 秒后切回 |
| 部分供电 | 主动通量按供电比例下降 |
| 有缓存时保存/加载 | 元素、质量、热量、病菌保持 |
| 有缓存时拆除 | 等待排空，不删除物质 |
| 20/100/500 格膜墙 | 吞吐线性扩展，性能可接受 |

## 25. 成功标准

V1 可视为设计目标达成，当以下条件同时满足：

- 膜砖和膜门在任何正常运行状态下都不会产生非授权气液泄漏。
- 被动模式不耗电且行为稳定可预测。
- 主动模式支持方向控制、逆浓度输运、微缓存和按供电比例降速。
- 多元素白名单不会覆盖不兼容目标 Cell。
- 大面积膜网络只需任意一处外部供电即可让整个连通网络使用主动能力。
- 多外部电网只作为主/备用来源，绝不通过膜网络互相送电。
- 分子筛门保留复制人权限、锁定和自动化控制，同时实现零泄漏通行。
- 存档、拆除、断电与异常路径均不吞质量。
- 不依赖全局气液模拟改写，主要逻辑保持在本 Mod 自身组件范围内。
