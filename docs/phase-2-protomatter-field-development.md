# 禁忌科技建筑包：第二阶段“原质场与维度耦合”开发文档

> 本文档是第二阶段的具体开发基线，补充 `docs/phase-2-development-guide.md`。现有第一阶段代码、稳定 ID、配置、安全移除和测试规则继续有效，不允许为了第二阶段回退或重写已验证的一阶段实现。

## 1. 阶段目标

第一阶段已经完成“物质解析 → 物质解构 → 原质 → 物质编译”的基础物质工程闭环，并且原质已经是可搬运、可储存、可进入固体物流的实体材料。

第二阶段不再解决原质的实体化、基础储存或基础运输，而是回答：**原质作为一种部分脱离常规物质维度的实体材料，还能支持什么工程能力。**

第二阶段主题统一为：

**原质场与维度耦合（Proto-Matter Field & Dimensional Coupling）**

本阶段引入三台建筑：

1. 物质重构器（Matter Reconstructor）
2. 熵流偏转器（Entropy Flux Diverter）
3. 物质湮灭堆（Matter Annihilation Reactor）

同时正式引入一套只作用于本 Mod 禁忌建筑的“原质干扰”系统，使禁忌建筑第一次形成系统级关联，而不是继续堆叠互不相关的独立机器。

---

## 2. 世界观与玩法边界

禁忌科技并不是更先进的常规科技，而是一套建立在另一层物质规则之上的工程体系。

原质在游戏世界中表现为实体固体，复制人可以搬运，储存器可以储存，固体运输轨道可以运输；但其稳定状态并不完全位于常规物质维度。

因此现有建筑统一解释为：

- **物质分析仪**：读取普通物质的结构模板，而非只做成分扫描。
- **质量粉碎机**：破坏普通物质的现实结构，使其脱离原有物质态并形成原质。
- **物质编译器**：根据已记录结构模板，将原质重新锚定为正常物质。

第二阶段三台建筑进一步使用这种维度特性：

- **物质重构器**：不完全解除现实锚定，而是利用少量原质直接改写已有材料的结构。
- **熵流偏转器**：利用原质场改变两个物质系统之间的热力学耦合，使熵流沿指定方向重新分布。
- **物质湮灭堆**：主动解除原质与当前现实维度的锚定，以质量亏损形式释放高密度能量。

普通建筑没有原质场接口，因此原质场异常不直接影响普通建筑、电网、自动化和第三方 Mod 建筑。

禁忌建筑拥有与原质维度发生耦合的接口，因此会响应原质干扰。

这一边界既是世界观规则，也是代码实现边界。

## 3. 第二阶段总资源闭环

第一阶段：

`普通物质 → 物质分析 → 质量粉碎 → 原质 → 物质编译 → 普通物质`

第二阶段增加原质消费分支：

### A. 完全编译

`原质 → 物质编译器 → 已分析材料`

特点：自由度高，原质消耗高。

### B. 结构重构

`普通材料 A + 少量原质 → 物质重构器 → 普通材料 B`

特点：保留大部分质量，只利用原质完成结构改写；转换关系受限制。

### C. 熵流控制

`高温介质 + 低温介质 + 原质 + 电力 → 熵流偏转器 → 热量重新分布`

特点：不凭空删除热量，而是以原质场突破普通传热效率限制。

### D. 高密度能源

`原质 + 启动/维持电力 + 冷却能力 → 物质湮灭堆 → 大量电力 + 巨量热`

特点：高收益、高工程门槛、有独特但非毁灭性的失控风险。

第二阶段的核心资源决策因此变成：玩家必须决定有限原质用于材料、热管理还是能源。

## 4. 共用系统：禁忌建筑与原质干扰

### 4.1 技术目标

第二阶段即实现禁忌建筑之间的原质场干扰，不把这一能力继续推迟到第三阶段。

所有当前及未来禁忌建筑应接入统一的设备组件，建议命名：

`ForbiddenTechDevice`

组件职责只包括：

- 标识该建筑属于禁忌科技设备；
- 保存当前是否受到原质干扰；
- 接收干扰开始/结束事件；
- 为具体建筑提供稳定的查询接口；
- 不直接包含具体建筑的生产逻辑。

原质干扰的范围事件由独立管理器处理，建议命名：

`ProtoMatterInterferenceManager`

### 4.2 实现边界

必须遵守：

- 不 Patch 原版所有建筑；
- 不修改第三方 Mod 建筑；
- 不修改整个电网或自动化网络；
- 不做每帧全图建筑扫描；
- 干扰产生时做一次范围查询/广播；
- 干扰结束时移除对应状态；
- 仅响应带 `ForbiddenTechDevice` 的本 Mod 建筑；
- 保存/加载后状态必须可恢复或安全重建；
- 已关闭新建筑配置时，不允许破坏存档中的已建实例。

### 4.3 第一阶段建筑的干扰表现

第二阶段上线后，现有三台建筑也应接入 `ForbiddenTechDevice`。

第一版建议行为：

- **物质分析仪**：受到干扰时暂停分析，保留已有分析进度和结果。
- **质量粉碎机**：受到干扰时降低运行效率或暂停原质生成；第一版优先选择“暂停”，避免质量计算复杂化。
- **物质编译器**：受到干扰时暂停编译，保留工作单和输入物料。

原则：干扰不能吞物料、复制物料、清空队列或破坏存档。

### 4.4 第二阶段建筑的干扰表现

- **物质重构器**：暂停重构，保留输入和工作单。
- **熵流偏转器**：停止主动熵流偏转，转入安全旁路/停机状态，不凭空改变管道内物质质量。
- **物质湮灭堆**：自身失控源不依赖外部干扰停机逻辑；发生退相干后进入专门的锁定恢复状态。

## 5. 建筑一：物质重构器

### 5.1 定位

物质重构器不是第二台物质编译器。

物质编译器执行：

`原质 → 目标材料`

物质重构器执行：

`基础材料 + 少量原质 → 目标材料`

它利用原质场直接修改已有物质结构，用更少原质换取受限制的材料升级。

### 5.2 第一版原则

- 只允许明确白名单转换，不自动生成“所有元素互转”配方；
- 输出总质量原则上不得无理由大于输入总质量；
- 原质是催化/重构成本的一部分，并实际消耗；
- 目标材料原则上要求已经通过物质分析仪完成结构解析；
- 复用现有材料分类、解锁状态与 Fabricator 体系；
- 支持复制设置、优先级、电力和自动化；
- 工作中发生原质干扰时安全暂停。

### 5.3 开发优先级

这是第二阶段第一台开发建筑，用来验证：

- 第二阶段稳定 ID；
- 新配置项；
- 新研究解锁；
- `ForbiddenTechDevice`；
- 干扰事件；
- 新建筑 KAnim；
- 工作单、存档、禁用配置和安全移除。

## 6. 建筑二：熵流偏转器

### 6.1 命名

正式名称：**熵流偏转器**

英文：**Entropy Flux Diverter**

不再使用“禁忌热交换器”作为正式名称。

### 6.2 定位

它不是一个单纯高性能液冷机，也不允许无条件删除热量。

设定：

> 熵流偏转器利用原质场重新建立两个物质系统之间的热力学耦合关系，使热量沿人为指定的方向重新分布。

### 6.3 第一版工作逻辑

推荐使用两路液体系统作为第一版实现，避免同时支持气体、液体、多相态导致开发量失控。

输入：

- 热侧液体；
- 冷侧液体；
- 原质；
- 电力。

输出：

- 降温后的热侧液体；
- 升温后的冷侧液体。

约束：

- 总质量守恒；
- 热量转移必须有明确来源和去向；
- 原质作为异常耦合成本实际消耗；
- 达到冻结点/沸点等相变边界时必须采用安全策略，不能静默制造错误物态；
- 管道阻塞时停机，不吞液体；
- 受到原质干扰时停止主动偏转。

第一版不做：

- 全元素任意跨相态传热；
- 直接指定目标温度并无限追踪；
- 无来源的“删除 DTU”；
- 复杂建筑范围场效果。

## 7. 建筑三：物质湮灭堆

### 7.1 定位

正式名称：**物质湮灭堆**

英文：**Matter Annihilation Reactor**

外观和工程语言可以采用托卡马克式大型环形磁约束装置，但内部机制不是传统核聚变。

原质被注入环形约束腔后，设备维持其与现实空间的稳定边界，并主动解除其现实锚定，以质量亏损形式释放能量。

### 7.2 正常运行

核心关系：

`原质 + 启动/维持电力 + 冷却 → 大量电力 + 巨量热`

必须先耗电建立约束场，再进入净发电状态。

禁止设计成停电状态下可无条件黑启动的普通发电机。

首版需要明确区分：

1. 停机；
2. 约束充能；
3. 稳定反应；
4. 约束波动；
5. 退相干临界；
6. 退相干失控；
7. 冷却锁定；
8. 可重新启动。

### 7.3 失控机制

失控不采用普通核反应堆式：

- 爆炸；
- 永久建筑摧毁；
- 熔毁后整套设施报废；
- 大范围删除玩家建筑。

正式失控链：

`约束波动 → 退相干临界 → 原质退相干`

#### 约束波动

冷却不足、维持供电异常或反应条件超出稳定区后进入。

表现：

- 发电输出不稳定或下降；
- 约束维持成本上升；
- UI/状态条明确警告；
- 动画出现场环抖动；
- 给玩家处理时间。

#### 退相干临界

持续恶化后进入临界状态并尝试自动停堆。

#### 原质退相干

若无法恢复：

- 当前反应批次损失一部分原质；
- 产生一次明显热脉冲；
- 在一定范围产生原质干扰；
- 受影响禁忌建筑进入对应干扰状态；
- 湮灭堆本体强制停机并锁定；
- 建筑本体不爆炸、不永久销毁。

### 7.4 恢复流程

`停止反应 → 冷却至安全阈值 → 原质场恢复稳定 → 重新建立约束 → 再次启动`

失控惩罚应主要体现在：

- 原质损失；
- 发电中断；
- 热管理压力；
- 禁忌科技区短时停摆；
- 重新启动时间。

而不是摧毁玩家长时间建设的反应堆系统。

### 7.5 干扰范围

二阶段第一版即影响附近禁忌建筑。

范围内普通建筑完全不响应。

范围内 `ForbiddenTechDevice`：

- 接收干扰开始事件；
- 显示“原质干扰”状态；
- 按自身规则暂停/降级；
- 干扰结束后恢复。

第一版可增加复制人的“现实错位”状态，但它是表现层扩展，不得阻塞禁忌建筑干扰主链实现。

## 8. 研究与解锁

第一阶段研究 `BaiyeForbiddenMatterEngineering` 保持稳定，不改 ID。

第二阶段新增独立研究，建议稳定 ID：

`BaiyeForbiddenProtoFieldEngineering`

中文名建议：**原质场工程**

推荐关系：

`禁忌物质工程 → 原质场工程`

第二阶段三台建筑全部由“原质场工程”解锁。后续如果湮灭堆需要进一步提高终局门槛，可以在第三阶段再拆研究节点；第二阶段第一版保持一个新增研究节点，避免研究树复杂化。

## 9. 配置设计

继续使用现有 `ForbiddenTechOptions` 单一中文 PLib 配置页，不创建第二个配置窗口。

新增至少以下独立开关：

- 启用物质重构器；
- 启用熵流偏转器；
- 启用物质湮灭堆。

新增建筑开关只控制：

- 新游戏/重启后的注册；
- 建造菜单显示；
- 研究解锁内容。

不得因为关闭配置而破坏已经存在于存档中的建筑实例。

第一版数值优先复用现有：

- `PowerMultiplier`；
- `HeatMultiplier`；
- `CostMultiplier`。

只有确实无法表达第二阶段行为时才增加新的数值选项，避免配置页膨胀。

## 10. 存档与安全移除

第二阶段所有新增建筑必须纳入现有安全移除流程。

要求：

- 移除前转换/释放建筑内存储的原质；
- 不吞掉普通输入材料；
- 不吞掉管道/轨道中的输出；
- 正在执行的工作单必须安全取消或保留；
- 湮灭堆处于失控/锁定状态时也必须可以安全清理；
- 干扰管理器不得在建筑已删除后持有失效引用；
- 完成安全移除后另存新档并重新载入验证，再允许关闭 Mod。

稳定 ID 一经提交发布不得修改。

## 11. 动画与表现

第二阶段仍遵循现有资源规则：

- 原始资源只修改 `assets/scml/<module>/`；
- `packaging/anim` 与 `dist` 是生成结果，不手工编辑；
- 更新 `assets/animation-manifest.json`；
- 建造菜单必须有独立 UI timeline/icon；
- 工作动画至少包含 idle / working / disabled；
- 湮灭堆额外需要 charge / unstable / locked 等状态；
- 不允许为了视觉效果引入每帧重逻辑。

湮灭堆视觉方向：托卡马克式环形约束结构 + 非传统核聚变的原质场表现。失控表现应是约束环不连续、向内坍缩、场光消失和余热，而不是普通爆炸火球。

## 12. 开发顺序

### 第一阶段：公共原质场基础

先实现：

- 第二阶段稳定 ID；
- 配置开关；
- 第二阶段研究；
- `ForbiddenTechDevice`；
- `ProtoMatterInterferenceManager`；
- 一阶段三台建筑接入干扰；
- 纯逻辑干扰策略测试。

### 第二阶段：物质重构器

完成完整 Config、运行组件、配方、动画、本地化、存档和安全移除。

### 第三阶段：熵流偏转器

先做双液体版本，重点验证热量守恒、相变边界、管道阻塞和干扰停机。

### 第四阶段：物质湮灭堆

最后实现完整状态机、启动耗电、净发电、冷却、约束波动、退相干、热脉冲、范围干扰和恢复流程。

原因：湮灭堆依赖公共干扰系统和前两台建筑对第二阶段框架的验证，不应作为第一项直接堆复杂状态机。

## 13. 测试要求

现有 `docs/test-matrix.md` 在第二阶段增加以下验证项。

### 自动测试

- 第二阶段三个稳定 ID 不变；
- 三个配置开关注册行为正确；
- 模块总开关仍能隐藏全部禁忌建筑；
- 干扰范围策略只命中禁忌设备；
- 干扰开始/结束幂等；
- 重构配方质量与解锁条件正确；
- 熵流计算满足质量守恒与热量来源/去向约束；
- 湮灭堆状态转换可预测；
- 原质损失与热脉冲计算有上下界；
- 安全移除包含二阶段建筑。

### 游戏内验证

- 三台新建筑研究与菜单正常；
- 图标不显示问号；
- 动画状态完整；
- 分别建造、运行、停机、自动化禁用；
- 保存并重载；
- 配置关闭后已有实例不丢失；
- 湮灭堆失控只影响范围内禁忌建筑；
- 普通建筑不受干扰；
- 干扰结束后禁忌建筑恢复；
- 失控不会爆炸或永久摧毁建筑；
- 安全移除后另存并重载通过；
- `Player.log` 无本 Mod 重复异常。

### 性能验证

- 原质干扰不得每帧全图扫描；
- 多台湮灭堆触发干扰时状态可叠加/刷新但不重复注册无界事件；
- 20 台以上禁忌建筑的干扰测试无明显持续帧耗；
- 10 台重构器 + 10 台熵流偏转器运行 20 周期无队列或存储无界增长。

## 14. 第二阶段完成定义

只有同时满足以下条件，第二阶段才允许标记完成：

1. 公共原质场/禁忌建筑干扰系统上线；
2. 三台新建筑全部可建造并完成核心功能；
3. 湮灭堆具有完整非毁灭性失控与恢复流程；
4. 普通建筑不受原质干扰；
5. 配置、存档、安全移除和本地化完成；
6. 自动测试通过；
7. KAnim、DLL、package、ZIP 验证通过；
8. Steam 启动与真实殖民地验证通过；
9. `docs/test-matrix.md` 对应行有真实执行记录。

在真实游戏验证完成以前，不以“代码已写完”替代“第二阶段已完成”。
